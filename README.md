# Bio-Page

My personal bio page: a short CV in one HTML file.

**Live page:** https://oleksiisyrotkin.github.io/Bio-Page/bio_page.html

## What's inside

- short info about me and what I do as a QA engineer
- links to my test automation projects with reports
- tools I work with
- work experience
- contacts

## How it's made

One file, `bio_page.html`. Plain HTML and CSS, no frameworks and no JavaScript. Fonts are from Google Fonts, the photo is taken from my GitHub avatar.

The page is responsive, so it works on mobile, and it can be printed or saved as PDF from the browser (print styles hide the background and buttons).

Hosted on GitHub Pages from the `main` branch.

## Run locally

Just open `bio_page.html` in a browser, nothing to install.
